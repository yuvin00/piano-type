Windows와 macOS에서 다른 프로그램으로 타이핑할 때 피아노를 연주하는 앱입니다.

## 다운로드
- Windows 10/11 x64: Piano-Type-Windows.exe
- macOS: Piano-Type-macOS-universal.zip (Apple Silicon 및 Intel 공용)

## Mac 설치와 권한
1. ZIP을 압축 해제하고 Piano Type.app을 응용 프로그램 폴더로 옮기세요.
2. 앱을 실행하고 미니 피아노 열기를 누르세요.
3. 시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용에서 Piano Type을 허용하세요. 입력 모니터링 권한도 요청되면 허용하세요.
4. 권한을 바꾼 뒤 앱을 완전히 종료하고 다시 실행해야 할 수 있습니다.

Mac 빌드는 Apple Developer ID 서명·공증이 없는 빌드입니다. 출처를 확인하고 신뢰하는 경우에만 macOS가 제공하는 개인정보 보호 및 보안의 '확인 없이 열기' 절차를 사용하세요. 보안 기능을 전체적으로 끄지 마세요. 회사나 학교의 정책에 따라 실행이 제한될 수 있습니다.

## 사용
미니 피아노 열기로 전체 타자 소리와 작은 피아노 창을 켭니다. Windows는 Ctrl+Alt+P, Mac은 Command+Option+P로 켜고 끕니다. 완전 종료는 트레이/메뉴 막대의 Piano Type 메뉴에서 종료를 선택하세요.
외부 입력 내용은 저장·전송하지 않으며 비밀번호 입력에도 소리가 날 수 있습니다.

GitHub macOS/Windows 환경에서 앱을 빌드하고 기본 테스트와 네이티브 모듈 로딩을 확인합니다. 실제 Mac에서의 권한 승인·전체 타자 감지·청음은 별도 확인이 필요합니다.
